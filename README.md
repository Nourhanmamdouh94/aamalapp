# A'amal prototype (Figma Make wrapper)
Vite + React app that hosts the finished A'amal prototype inside an iframe.
- Prototype files: `public/aamal/` (index.html, index-ar.html, fonts/)
- Wrapper: `src/App.jsx`
Run: `npm install && npm run dev`
To update the prototype, replace the files in `public/aamal/`.
